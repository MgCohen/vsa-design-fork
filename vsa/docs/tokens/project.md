# Project tokens

A project token, `--vsa-*`, is only for an idea that Web Awesome has no token for. It is never a second name for a Web Awesome token. The theme layer sets them in the same three blocks as the `--wa-*` tokens.

| Group | Use |
|---|---|
| Shadows | The raised and carved looks: `raise`, `carve`, `press`, `knob`, `glow`, `dial`, `hole` |
| Gradients | The canvas, the raised surface, the knob and the dial center |
| Type | The letter spacing and the weight of the display font |
| Code | The colors of a code block, in `theme/code.css` |

```tokens ^--vsa- @vsa.css
```

```tokens ^--vsa- @code.css
```
