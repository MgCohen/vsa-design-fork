# Typography

Body text and controls use Inter. Headings use Doto. Code uses JetBrains Mono.

## Families

```tokens ^--wa-font-family-(body|heading|code)$
```

## Sizes

The VSA sizes are smaller than the Web Awesome defaults. The size `m` is the body size, 13 px.

```tokens ^--wa-font-size-(2xs|xs|s|m|l|xl|2xl|3xl)$
```

## Weights and line heights

```tokens ^--wa-(font-weight-(body|action|semibold)|line-height-(condensed|normal))$
```
