# Spacing

Components and pages use the Web Awesome space scale, `--wa-space-*`. The theme does not change it. Use these tokens for each gap and padding. Use the layout utilities, for example `wa-stack`, `wa-cluster` and `wa-gap-*`, before you write flex or grid.

```tokens ^--wa-space-(3xs|2xs|xs|s|m|l|xl|2xl|3xl)$
```
